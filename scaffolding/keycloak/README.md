# Keycloak Scaffolding Directory

This directory contains all scripts, Dockerfiles, and documentation for the Keycloak container in the Pure Bliss stack.

- All automation scripts must use centralized utilities from /opt/dev-purebliss/dev_scripts/utilities/
- Health validation and integration steps are documented in keycloak-documentation.md
- Follow the one-container-at-a-time, health-gated methodology
